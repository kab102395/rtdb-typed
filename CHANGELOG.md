# Changelog

All notable changes to this project are documented here.

## 0.3.0 - Unreleased

- Added first-class typed realtime events with explicit deletion semantics.
- Added `TypedPatch` inspection and model-application helpers.
- Added direct typed streams and cancel-aware termination.
- Added pure, mock-SSE, emulator realtime, fan-out, and stress coverage.

## 0.2.0 - 2026-08-26

- Added `FirebaseCollection<T>` for typed Firebase object maps.
- Added nullable and collection query result helpers.
- Added stable `PushResult` values with generated key and derived path.
- Expanded pure, localhost, and emulator stress coverage.

## Unreleased

- Harden typed collection, query, and realtime event semantics.
- Add localhost protocol tests and demo-project emulator stress coverage.
